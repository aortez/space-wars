## Fixed search policy

Keep the ordinary sparse survey and four original offsets first. Return its
ordinary site if any passes. Otherwise, treat a tested coarse footing as
promising only when it passed the early native geometry checks but failed
hatch footing, hatch routing or hatch-route length.

Refine measured nodes within two units of those promising footings, including
the original footing itself. Sort each neighborhood by distance and bearing;
visit them round-robin, deduplicating nodes. Test at most eight refined nodes
per original survey tick, without a new survey cadence. Retain the same local
patch and 24-unit outbound/hatch route limits. Refined outbound routes must
reach the actual target node within 0.01 units.

At each refined node, and at actual native rebuild attempts when enabled, try
the original four offsets first. Only if none works, try the 22 half-unit
offsets strictly between 8 and 14 on both sides. Existing accepted placements
retain their precedence. Every proposal uses the shared native ground,
alignment, hull, other-seat, footing and hatch-route checks.

The hard survey bounds are eight coarse candidates, eight refined candidates
and 240 placement-offset evaluations. Actual rebuild attempts use at most 26
offsets on the existing native retry cadence. This is a bounded increase in
work, not a claim of unchanged per-frame cost. Work counters and every candidate
are recorded. There are no hard-coded world bearings, positions or successful
offsets from the probe.

## Refined arrival and native execution

Mark refined standing sites as requiring precise arrival. The recovery task
passes that requirement to its ordinary ground task without resetting recovery
history or budgets. Plan to the exact measured node and require the current
foot to be within 0.12 units, with actual native support, before ground arrival.
Unrefined sites and other destinations keep their existing behavior.

Arrival is not a build receipt. Native recovery must recheck placement at the
actual supported position, complete its existing build timer and spawn a real
ship. Landing, two-foot support, settling time and human boarding gates remain
unchanged. Keep the four-relocation limit, five-second missing-site budget,
existing traversal/stall limits and fixed end tick 29421.

and live-task continuations. In the refined recorded-controls arm, generated
